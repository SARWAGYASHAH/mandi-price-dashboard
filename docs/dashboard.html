Power BI Design

Four pages, one analytical story.

These previews are generated directly from the cleaned dataset using Matplotlib and act as the visual build reference for the documented Power BI model and DAX layer.

Canvas: 16:9 · 1280×720
Theme: Deep navy + saffron highlights
Slicers: Date · Commodity · State · Season
Tooltips: Quote count in every visual
01

National Overview

Executive summary with KPI cards for average modal price (₹2,475), total market entries (736,711), and anomaly count (16,336). Multi-line trend chart by commodity, clustered bar comparison, seasonal matrix, and anomaly concentration donut.

02

State Wise Comparison + India Map

India filled map with sequential light-to-dark saffron shading (light = cheaper, dark = expensive). Top 10 state ranking bar, price-vs-coverage scatter plot sized by anomaly count, and a state × commodity matrix with price rankings.

03

Crop Deep Dive

Single-select commodity analysis. Daily median with 30-day rolling average line, MoM/YoY change KPIs, price volatility index, seasonal average bars, cheapest and most expensive market cards, and top markets by reporting frequency.

04

Market Intelligence + Anomaly Flags

Anomaly investigation page with 16,336 flagged records. State and commodity anomaly bars, observed-vs-rolling price scatter (normal vs anomaly colored), highest-severity detail table with z-scores, and conditional formatting for flags.

functions 18 DAX Measures

  • Base: Avg Modal Price, Max/Min Price, Total Entries
  • Trend: MoM Change %, YoY Change %, 30-Day Rolling Avg, Volatility Index
  • Comparison: State Rank, Top 5 Markets, Cheapest/Expensive Market
  • Seasonal: Season Avg, Peak/Lowest Price Month
  • Anomaly: Total Count, % by State, % by Commodity

schema Data Model

  • MandiPrices — 736,711 row fact table (quote-level)
  • DimDate — Continuous calendar with Year, Month, Quarter, Season
  • Relationship: DimDate[Date] → MandiPrices[arrival_date] (1:M)
  • State: data category State or Province (for India map)
